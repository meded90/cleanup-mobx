# cleanupRequestAnimationFrame

`cleanupRequestAnimationFrame`
**AST Node Type:** *FunctionDeclaration*

> Setup/cleanup wrapper for requestAnimationFrame. On rerun, the previous frame is cancelled and its cleanup runs.

#### Parameter:

- `cb`  — function called in the animation frame; may return an optional cleanup function.
#### Returns:
  for cancelling the requested frame and running cleanup.
#### Example:
```ts
const dispose = cleanupRequestAnimationFrame(() => {
  // animation code
  return () => {
    // optional cleanup
  }
})

// Cancel and clean up:
dispose()
```

#### Source Code:

```ts
export function cleanupRequestAnimationFrame(cb: () => Disposer): () => void {
    let dispose: void | (() => void);
    let isCancelled = false;
    function innerCb() {
        if (isCancelled) {
            return;
        }
        const effect = cb();
        dispose = isFunction(effect) ? effect : undefined;
    }
    const animationFrameId = requestAnimationFrame(innerCb);
    return () => {
        isCancelled = true;
        dispose?.();
        cancelAnimationFrame(animationFrameId);
    };
}

```
