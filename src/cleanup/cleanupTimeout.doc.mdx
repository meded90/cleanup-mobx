# cleanupTimeout

`src/cleanup/cleanupTimeout`
**AST Node Type:** *FunctionDeclaration*

> Setup/cleanup wrapper for setTimeout: when rerun, the previous timeout is cleared and its cleanup runs.

#### Parameter:

- `cb`  — effect function called after the delay; may return a cleanup function.
- `delay`  — delay in milliseconds or a string accepted by ms().
- `dispose`  — optional cleanup function for the previous effect.
#### Returns:
  for cancelling the timeout and running cleanup.

#### Source Code:

```ts
export function cleanupTimeout(cb: () => void, delay: number | StringValue, dispose?: void | (() => void)): () => void {
    function innerCb() {
        const effect = action(cb)();
        dispose = isFunction(effect) ? effect : undefined;
    }
    delay = isString(delay) ? ms(delay) : delay;
    const timeoutId = setTimeout(innerCb, delay);
    return action(() => {
        dispose?.();
        clearTimeout(timeoutId);
    });
}

```
